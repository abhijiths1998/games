# Vintage collection

Original games in the style of late-80s and early-90s PC games. They share `common/retro.h`, a small header-only toolkit that provides:

- a 320×200 canvas with the EGA palette, shown at 4:3 with optional CRT scanlines (F2)
- a DOS-style 40-column font and dialog boxes
- a one-voice PC-speaker sound chip with pitch slides and priorities
- keyboard and gamepad input, pixel-art sprites from strings, and a high-score table

| Game | Style |
|---|---|
| [Relic Runner](relic-runner/) | EGA side-scrolling platformer: Sunstones, vault doors, jetpack, pistol |
